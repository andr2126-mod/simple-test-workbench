# Трассировка ВИ и требований FURPS+

| ВИ                                        | Функциональное                                           | Нефункциональное (категория FURPS+)                                                                                                                                            |
| ----------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ВИ-01 «Запустить набор тестов»            | запуск набора, исполнение тестов, фиксация результатов   | прогон набора из 10⁴ тестов укладывается в 15 минут за счёт параллельного исполнения (Performance)                                                                             |
| ВИ-02 «Просмотреть отчёт по прогону»      | сводка прогона, статусы тестов, ссылки на логи           | отчёт по прогону с 10⁴ результатов открывается не дольше 2 с; ключевая сводка видна без прокрутки (Performance, Usability)                                                     |
| ВИ-03 «Просмотреть историю прогонов»      | список прогонов, динамика стабильности по тестам         | запрос истории за 12 месяцев по 10⁶ записей выполняется не дольше 2 с за счёт индексов и агрегатов (Performance)                                                               |
| ВИ-04 «Выявить и маркировать флаки-тесты» | автоматическое выявление и маркировка флаки              | параметры эвристики (окно истории N, пороги) меняются конфигурацией без релиза; расчёт переживает сбой узла и доисполняется (Supportability, Reliability)                      |
| ВИ-05 «Настроить интеграцию с CI»         | привязка наборов к веткам, хранение токена CI            | токены CI хранятся в зашифрованном виде, доступ к настройкам только по роли администратора (Security)                                                                          |
| ВИ-06 «Триггер прогона из CI»             | приём события CI, создание прогона, возврат gate-статуса | доступность API не ниже 99,9% (CI блокируется целиком); приём запроса подтверждается за 1 с, сам прогон асинхронный (Reliability, Performance)                                 |
| ВИ-07 «Перезапустить упавшие тесты»       | повторный запуск подмножества упавших тестов             | перезапускаются только упавшие тесты, а не весь набор; повтор идемпотентен и не создаёт дубликат Run; все перезапуски журналируются (Performance, Reliability, Supportability) |
