# Трассировка ВИ и требований FURPS+

| ВИ | Функциональное | Нефункциональное (категория FURPS+) |
| --- | --- | --- |
| ВИ-01 «Запустить набор тестов» | запуск набора, исполнение тестов, фиксация результатов | прогон набора из 10⁴ тестов укладывается в 15 минут за счёт параллельного исполнения (Performance) |
| ВИ-02 «Просмотреть отчёт по прогону» | сводка прогона, статусы тестов, ссылки на логи | отчёт по прогону с 10⁴ результатов открывается не дольше 2 с; ключевая сводка видна без прокрутки (Performance, Usability) |
| ВИ-03 «Просмотреть историю прогонов» | список прогонов, динамика стабильности по тестам | запрос истории за 12 месяцев по 10⁶ записей выполняется не дольше 2 с за счёт индексов и агрегатов (Performance) |
| ВИ-04 «Выявить и маркировать флаки-тесты» | автоматическое выявление и маркировка флаки | маркировка по итогам прогона из 10⁴ тестов завершается не позднее чем через 60 с после его окончания; при сбое узла расчёт возобновляется и завершается не позднее чем через 5 минут (Performance, Reliability); окно N и пороги меняются конфигурацией без релиза (Supportability) |
| ВИ-05 «Настроить интеграцию с CI» | привязка наборов к веткам, хранение токена CI | токены CI хранятся в зашифрованном виде, доступ к настройкам только по роли администратора (Security) |
| ВИ-06 «Запустить прогон по событию CI» | приём события CI, создание прогона, возврат идентификатора Run и итогового статуса при опросе | доступность API не ниже 99,9% (CI блокируется целиком); приём запроса подтверждается за 1 с, сам прогон асинхронный (Reliability, Performance) |
| ВИ-07 «Перезапустить упавшие тесты» | повторный запуск подмножества упавших тестов | перезапуск 10³ упавших тестов стартует не позднее чем через 10 с после запроса; повторный запрос с тем же идемпотентным ключом создаёт 0 дубликатов Run; журнал перезапусков хранится не менее 3 лет (Performance, Reliability, Supportability) |
