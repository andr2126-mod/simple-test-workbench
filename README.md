# Система автоматического тестирования



Система автоматического тестирования - это централизованный сервис для управления, запуска и анализа результатов автоматизированных проверок. Основными пользователями системы являются QA-инженеры, разработчики и CI/CD-пайплайны (выступающие в роли внешних системных актеров). Она решает проблему фрагментации данных о качестве кода, предоставляя единую точку входа для запуска наборов тестов и получения структурированных отчётов. Система автоматически выявляет и маркирует «флаки-тесты» (нестабильные проверки), чтобы они не блокировали основной релизный процесс. Тесная интеграция с CI позволяет триггерить прогоны по событиям в репозитории, а встроенная история прогонов помогает командам отслеживать динамику стабильности тестов во времени. Граница системы проходит по API: внутри находятся управление тестовыми наборами, запуск, анализ результатов, отчёты и история прогонов, а исходный код, CI-сервер и среды исполнения тестов остаются во внешнем окружении.
